GS1 Digital Link resolver

This address resolves GS1 Digital Links: scanning the QR code on a product takes you to the information its brand owner has published.

On this resolver

  • Link management portal

    Register GTINs and batches and choose where each product's GS1 Digital Link QR code leads. Requires a username and password.

    Open the portal

  • Resolver API (Swagger UI)

    Interactive documentation of the Resolver CE data entry API, previously shown at the root of this address. For system integrations; writing requires an access token.
